# Svasth-HMS Client-Facing Landing Page

A high-converting, modern, dark-mode landing page designed to market and sell **Svasth-HMS White-Label Turnkey Hospital Management System** to doctor clinics, polyclinics, nursing homes, and multi-specialty hospitals.

---

## 🚀 Features Included in this Landing Page

1. **Interactive Screen Previews**:
   - Tab 1: OPD Reception & Token Queue (Day Board, Tokens, Vitals)
   - Tab 2: Doctor Digital Prescription Pad (Generic search, protocol templates, letterhead preview)
   - Tab 3: IPD Inpatient & Bed Matrix (Realtime bed occupancy, case sheets, 2-click discharge summary)
   - Tab 4: Hospital Billing & Collections (Consultation fee rules, procedure catalog, dues ledger)

2. **Core Clinical Features Breakdown**:
   - OPD Token Queue, Digital Rx, IPD Bed Management, Letterhead/Thermal Printing, WhatsApp/Email Dispatch, and 100% Isolated Database.

3. **Specialties Supported**:
   - Orthopaedics & Joint Replacement, Obstetrics & Gynaecology, Dental Clinics, Multi-Specialty, and Daycare Surgery.

4. **Doctor & Hospital Case Studies**:
   - Verified feedback from Cortex Hospital & Research Centre and senior specialists.

5. **Interactive Time & ROI Calculator**:
   - Sliders for Daily OPD Patients and Monthly IPD Admissions displaying live monthly hours and rupee savings.

6. **Transparent Tiered Pricing (Starting from ₹25,000)**:
   - **Starter Clinic Edition**: ₹25,000 one-time + ₹2,499/mo
   - **Multi-Doctor Specialty (Most Popular)**: ₹45,000 one-time + ₹4,499/mo
   - **Full Enterprise Hospital (OPD + IPD)**: ₹75,000 one-time + ₹7,999/mo

7. **Lead Capture & WhatsApp Integration**:
   - Interactive "Book Live Demo" modal that automatically composes a WhatsApp message to your team (`+91 9373280505`).

## 🛠️ Development & Deployment

### Run Local Development Server:
```bash
npm run dev
```

### Build for Production:
```bash
npm run build
```
The static production build is output to the `dist/` directory (~230 KB compressed) and can be deployed directly to:
- Hostinger (e.g. `svasthhms.com` or `get.svasthhms.com`)
- Vercel (`npx vercel`)
- Cloudflare Pages / Netlify
